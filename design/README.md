## Шрифты

Используем три шрифта, у каждого своя задача. Все бесплатные (Google Fonts, лицензия OFL) и поддерживают **кириллицу**. Это главное условие: интерфейс на русском.

### 1. Unbounded — акцентный (display)

- **Для чего:** логотип, заголовки страниц (H1–H2), крупные заголовки на лендинге, названия секций.
- **Начертания:** 500 (Medium), 700 (Bold).
- **Характер:** широкий геометрический гротеск с «техническими» скруглёнными формами. Похож на маркировку на промышленном оборудовании, поэтому подходит к теме склада и роботов.
- **Правила:**
  - Только крупно, от 16px. Мелким текстом не используем: широкие буквы плохо читаются.
  - Логотип набирается в верхнем регистре, межбуквенный интервал `0.04em`.
  - В заголовках обычный регистр, интервал `-0.01em`.
  - Не больше одного-двух заголовков этим шрифтом на экране.

### 2. Inter — основной (UI / текст)

- **Для чего:** весь интерфейс: навигация, кнопки, формы, таблицы, описания, тосты, модалки.
- **Начертания:** 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold).
- **Характер:** нейтральный, отлично читается мелким кеглем на экране, хорошая кириллица.
- **Правила:**
  - Основной текст 14px / line-height 1.5.
  - Кнопки и пункты меню 14px, начертание 500–600.
  - Подписи, метки, бейджи 11–12px, начертание 500–600. Метки групп (например «КОМАНДА» в сайдбаре) в верхнем регистре, интервал `0.08em`.

### 3. JetBrains Mono — моноширинный (данные)

- **Для чего:** всё, что является «данными симуляции»: координаты клеток `(12, 3)`, ID заданий `#T-318`, время в журнале событий `14:02:41`, размер карты `20×20`, счётчики в статистике.
- **Начертания:** 400, 500.
- **Почему моноширинный:** цифры одной ширины, поэтому числа, которые меняются в реальном времени, не «прыгают», а колонки журнала ровно выравниваются.
- **Правила:** крупные числа в карточках статистики 30px / 500, в тексте 12–13px.

### Подключение в Next.js

Сейчас в `frontend/src/app/layout.tsx` подключены Geist и Geist Mono только с `latin`, кириллицы в них нет. Когда будем внедрять дизайн, можно заменить так (это пример, код проекта пока не трогаем):

```tsx
import { Unbounded, Inter, JetBrains_Mono } from "next/font/google";

const display = Unbounded({ subsets: ["latin", "cyrillic"], weight: ["500", "700"], variable: "--font-display" });
const sans    = Inter({ subsets: ["latin", "cyrillic"], variable: "--font-sans" });
const mono    = JetBrains_Mono({ subsets: ["latin", "cyrillic"], weight: ["400", "500"], variable: "--font-mono" });

// <html className={`${display.variable} ${sans.variable} ${mono.variable}`}>
```

```css
@theme inline {
  --font-display: var(--font-display);
  --font-sans: var(--font-sans);
  --font-mono: var(--font-mono);
}
```

Fallback-стеки: `Unbounded, sans-serif` · `Inter, system-ui, sans-serif` · `"JetBrains Mono", ui-monospace, monospace`.

## Роботы

Вид 3/4 сверху, холст `64×64`, одна клетка карты. Для каждого робота 4 файла:

```
robots/<name>/<name>_up.svg      — едет вверх (видна спина)
robots/<name>/<name>_down.svg    — едет вниз (видна «морда»)
robots/<name>/<name>_left.svg    — едет влево
robots/<name>/<name>_right.svg   — едет вправо
```

| Робот | Цвет | Описание |
| --- | --- | --- |
| **mule** («Мул») | оранжевый `#FF8A1F` | Низкий AGV-перевозчик с подъёмной платформой. Базовый робот. |
| **lifter** («Штабелёр») | жёлтый `#FFC53D` | Автономный погрузчик с мачтой и вилами. |
| **picker** («Сборщик») | синий `#4C9AFF` | Высокий робот с манипуляторами и экраном-лицом. |

Выбор спрайта по направлению движения (робот ходит только по соседним клеткам, без диагоналей):

```ts
type Dir = "up" | "down" | "left" | "right";
const dirOf = (from: {x:number;y:number}, to: {x:number;y:number}): Dir =>
  to.x > from.x ? "right" : to.x < from.x ? "left" : to.y > from.y ? "down" : "up";

const src = `/robots/${model}/${model}_${dirOf(prev, next)}.svg`;
```

`left` — это зеркальная копия `right`. Если нужно перерисовать робота, правьте `generate.mjs` и запускайте:

```bash
node design/robots/generate.mjs design/robots
```

Статус робота лучше показывать не перекраской спрайта, а отдельным индикатором: цветным кольцом или точкой под роботом. Тогда модель робота остаётся узнаваемой в любом статусе.
