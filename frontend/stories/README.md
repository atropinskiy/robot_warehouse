# Storybook для Robot Warehouse

Storybook — каталог UI-компонентов. Открой историю в левом меню, чтобы посмотреть живой пример справа.

## Запуск

Выполни из корня репозитория:

```sh
cd frontend
pnpm install
pnpm storybook
```

Открой [localhost:6006](http://localhost:6006). Каждый разработчик запускает локальную копию у себя.

## Что смотреть

| Раздел                       | Что внутри                                                                                      |
| ---------------------------- | ----------------------------------------------------------------------------------------------- |
| **UI Kit → Typography**      | Шесть стилей `Heading` и варианты `Text`                                                        |
| **UI Kit → Controls**        | Кнопки, поля, подписи и метки. Нажми `Tab`, чтобы проверить фокус                               |
| **UI Kit → Layout**          | Карточки и раскладки `HStack` и `VStack`                                                        |
| **UI Kit → Icons**           | Каталог с именами для импорта. Поиск, AI, уведомления и плюс показаны в примере внутри каталога |
| **UI Kit → Спрайты роботов** | Мул, Штабелёр и Сборщик. У каждой модели четыре направления                                     |
| **Examples → Warehouses**    | Пример «Мои склады». Введи `Север`, чтобы отфильтровать демонстрационные карточки               |

## Где открыть код

Компоненты лежат в [`src/shared/ui`](../src/shared/ui), иконки — в [`src/shared/icons`](../src/shared/icons), примеры — в файлах `*.stories.tsx` рядом с этим README. Переход из Storybook в VS Code пока не настроен. Открой нужный файл в редакторе по этому пути.

```tsx
import { AddIcon } from "@/shared/icons";
import { Button } from "@/shared/ui";

<Button type="button">
  <AddIcon aria-hidden="true" />
  Новый склад
</Button>;
```

Для кнопки с одной иконкой задай `aria-label` на самой кнопке.

Спрайты из дизайн-макета лежат в [`public/robots`](../public/robots). В приложении путь к спрайту строится как `/robots/<модель>/<модель>_<направление>.svg`, например `/robots/mule/mule_right.svg`.
